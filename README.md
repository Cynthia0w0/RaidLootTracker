# 团队装备需求记录（Raid Loot Tracker）

一个魔兽世界团队插件，用于记录团队成员本周的装备需求与团本掉落分配情况。

## 安装

把整个 `RaidLootTracker` 文件夹放到魔兽世界的 AddOns 目录：

- 正式服：`World of Warcraft/_retail_/Interface/AddOns/`
- 经典服（60/70 等）：`World of Warcraft/_classic_/Interface/AddOns/`
- 怀旧服大灾变：`World of Warcraft/_classic_era_/Interface/AddOns/`

重启游戏或输入 `/reload`，然后在插件列表里勾选「团队装备需求记录」。

本插件按正式服（Midnight 12.x）填写接口版本号。如果你的客户端仍提示「不兼容」，请在游戏内聊天框输入下面的命令，把输出的数字发给我，我就能改成和你完全一致的版本号：

    /run print(select(4, GetBuildInfo()))

## 使用

### 打开/关闭表格

- 屏幕左下方小地图旁会有一个金币样式的图标，点击它即可打开或关闭记录表格。
- 也可以在聊天框输入 `/rlt` 或 `/raidloot` 开关表格。

打开表格后，会显示上次记录的团队成员名单（数据保存在账号级存档中，切换角色仍在）。

### 读取队伍

表格底部的「读取队伍」按钮会读取当前团队/队伍所有成员名称，并加入成员列表。

### 记录掉落

每个 Boss 结束后插件会自动打开「掉落分配记录」窗口；也可以在表格点「记录掉落」，或输入 `/rlt loot`。

流程：

0. 选中 Boss（把它设为当前目标），在「Boss：」输入框旁点「当前目标」，即可自动填入 Boss 名，无需手动打字。
1. 在左侧「本次掉落」列表选择一件装备（可点「读取掉落」从当前尸体拾取窗口读取；手动添加时，先点击「手动添加」输入框使其获得焦点，再 Shift+点击物品链接，点「添加」）。
2. 在右侧「选择成员」列表选择拿到该装备的成员。
3. 点击底部三个按键之一：
   - 需求（骰子图标）：记为需求获得
   - 贪婪（金币图标）：记为贪婪获得
   - 撤销（红叉图标）：删除当前所选装备已记录的内容，用于修正误记录

### 其他按键

- 历史记录：打开「装备分配历史」窗口，查看已经记录的每次掉落分配明细（Boss、装备、获得者、需求/贪婪）。
- 导出报告：把本周记录整理成文本，复制到聊天输入框，可直接粘贴发送。
- 清空记录：清空本周的掉落记录（成员名单保留）。
- 重置本周：手动开始新的一周，并清空本周掉落记录。
- 清空成员：清空成员名单。

插件会在距上次记录超过 7 天时自动判定为新的一周并清空上周掉落记录。

### 小彩蛋：最狗团员登记

在主表格的成员名单里，**右键点击某位成员**即可把他登记为「最狗团员」（再右键一次取消）。被登记的人名字前会显示一个狗头图标，顶部信息栏也会显示「最狗团员：xxx」。

## 斜杠命令

- `/rlt`：开关主表格
- `/rlt loot`：打开掉落分配窗口
- `/rlt reset`：重置本周记录

## 说明

- 需求/贪婪按键使用了游戏原生的「需求/贪婪」掷点图标，撤销键使用原生「放弃」红叉图标。
- 掉落自动读取尽力而为：会从拾取窗口、掉落历史和系统拾取消息中收集物品链接；如果个别情况没识别到，请用「读取掉落」或 Shift+点击物品链接手动添加。
- 数据保存在本机账号级存档，插件不会在玩家之间自动同步。
